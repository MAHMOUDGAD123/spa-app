HTML

HTML (HyperText Markup Language) is the backbone of web pages, defining their structure using elements like headings, paragraphs, links, and images. It works with CSS and JavaScript to create interactive websites.

CSS

CSS (Cascading Style Sheets) controls the look and feel of a webpage, allowing developers to style elements with colors, layouts, animations, and responsiveness for different screen sizes.

JavaScript

JavaScript is a powerful programming language that enables interactivity on websites, such as dynamic content updates, form validation, and animations, making web pages more engaging.

TypeScript

TypeScript is a superset of JavaScript that adds static typing, making it easier to catch errors early, improve code maintainability, and enhance large-scale application development.

NodeJs

Node.js is a runtime environment that allows JavaScript to run on the server side, enabling backend development, handling APIs, databases, and real-time applications efficiently.

ReactJs

React.js is a front-end JavaScript library for building user interfaces using reusable components, virtual DOM for performance optimization, and hooks for managing state efficiently.
